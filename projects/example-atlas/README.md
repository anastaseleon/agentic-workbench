# Project Atlas (example)

A fictional desk showing every format. Copy nothing from here into a real desk; use
`/new-project` instead.

## Goal

Retire the old reporting server by 2027-03-31 and move its twelve reports to the shared
reporting platform, with no report going dark for more than one business day.

## Scope

In scope: the twelve reports, their data feeds, their schedules.
Out of scope: redesigning the reports.

| Phase | Target date | Status |

| Discovery | 2026-12-15 | in progress |
